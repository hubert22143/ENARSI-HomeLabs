# ENARSI-HomeLabs

ENARSI-style networking labs focused on routing, policy, redistribution, troubleshooting.

## Folder Markers

Most folders are focused mini-labs. When a folder starts with `B-`, it means bigger lab: a larger topology, more than one topic at once, or a piece of work that deserves a fuller README because it took real troubleshooting to get there.

Example:

```text
B-multi-protocol-redistribution-route-tagging
```

That marker is meant to make the heavier homelabs easy to spot later, without making the repository feel overstructured.
